This folder is a placeholder for the visual assets (images, SVGs, fonts, Lottie json animations) that make up the ZIP UI package.

Please upload the actual assets into this folder (or into `assets/images`, `assets/fonts`, `assets/animations`) so the Compose components in `src/main/java/com/rek/ui` can reference them.

Suggested structure:
- assets/images/
- assets/fonts/
- assets/animations/

If you don't have the assets in this repo, you can keep them in a ZIP and I can fetch them when you provide the link.
